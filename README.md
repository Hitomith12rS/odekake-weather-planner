# おでかけ天気プランナー

## アプリ概要

旅行先の天気や太陽の位置を確認し、観光スポットでの風景撮影をサポートするWebアプリです。

訪問予定日の天気予報や日の出・日の入り時刻を確認できるほか、撮影日時とカメラの向きから太陽光の状態を判定できます。

## 制作目的

旅行先で風景や観光スポットを撮影する際に、天候や太陽光の向きを事前に確認できるツールを目指して制作しました。

単に天気を表示するだけでなく、撮影時の光の状態も確認できることを特徴としています。

## 主な機能

- **観光スポット選択**
  - 兵庫県内の観光スポットから撮影場所を選択
  - スポットの説明と位置情報を表示

- **天気予報**
  - 訪問予定日の天気・最高気温・最低気温・降水確率を表示

- **日の出・日の入り時刻**
  - 選択したスポットと訪問日に応じた時刻を表示

- **太陽位置・撮影サポート**
  - 撮影日時とスポットの位置情報から太陽の方角・高度を計算
  - カメラの向きに応じて順光・逆光・サイド光を判定

- **お気に入り機能**
  - 観光スポットのお気に入り登録・解除
  - localStorageを利用して登録情報を保存

## 使用技術

- HTML
- CSS
- JavaScript
- Open-Meteo API

- localStorage

## 工夫した点

- 訪問日と撮影日時を分けて指定できるようにし、旅行計画と撮影計画の両方に対応
- 太陽の方位角と撮影方向の角度差から、光の状態を判定
- スポット情報・天気取得・太陽位置の計算など、処理の役割に応じてJavaScriptファイルを分割
- localStorageの読み込み・保存時のエラー対策やデータ検証を実装
- スマートフォンでの利用を想定したレスポンシブデザインを採用
